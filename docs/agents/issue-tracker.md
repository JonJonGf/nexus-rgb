# Issue tracker: GitHub

Issues e especificações deste projeto ficam em [JonJonGf/nexus-rgb](https://github.com/JonJonGf/nexus-rgb/issues).

Use o conector GitHub disponível ou a CLI `gh`, quando instalada e autenticada. Identifique o repositório pelo remote e confira número, tipo e conteúdo do item antes de agir; issues e pull requests compartilham a numeração.

## Convenções

- Consulte os relatos existentes antes de criar para evitar duplicatas.
- Diferencie defeito reproduzido, hipótese, proposta e resultado físico observado.
- Para textos extensos com `gh`, prepare um arquivo e use `--body-file`, preservando as quebras de linha.
- Vincule decisões e resultados aos documentos de contexto e aos commits correspondentes; não copie todo o histórico da conversa.
- Quando uma skill pedir publicação no tracker, isso significa uma issue no GitHub, dentro da autorização do usuário. Sem autorização para a escrita externa, prepare o conteúdo localmente.
- A configuração deste tracker não autoriza comentários, mensagens, criação/fechamento de issues ou outras escritas externas por iniciativa própria. Respeite o escopo autorizado na conversa.

## Privacidade

Não publique credenciais, dados pessoais, diagnósticos crus ou arquivos privados de `data/`. Para vulnerabilidades, preserve o canal privado indicado em [Security Advisories](https://github.com/JonJonGf/nexus-rgb/security/advisories/new).

## Pull requests como origem de solicitações

**PRs as a request surface: no.**

## Triagem

A skill `triage` não foi instalada por este setup. Nenhuma etiqueta ou automação de triagem foi criada; preserve as convenções existentes do repositório.
