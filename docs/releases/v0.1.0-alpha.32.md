# Nexus RGB v0.1.0-alpha.32

Esta versão traz a **correção definitiva da contenção de taxa dupla no Studio (efeitos espaciais / mapa)**, garantindo que os módulos de memória RAM no barramento SMBus/I2C permaneçam estritamente contidos a 20 FPS sob qualquer efeito espacial, enquanto a placa-mãe e controladoras rodam a 60 FPS completos.

- **Eliminação do bypass de taxa no Studio:** na versão anterior, os ticks espaciais de animação do Studio (`hardware.tick(true)`) incrementavam a revisão interna de layout, marcando acidentalmente o quadro como `forceSend = true` e desativando a limitação de taxa de 20 FPS da RAM. A brecha foi corrigida: o limitador de cadência para barramento SMBus/I2C agora é incondicional durante a animação (apenas comandos de desligamento imediato e identificação manual possuem passe livre).
- **Taxa real comprovada no Studio:** com o efeito espacial rodando a 60 FPS no Studio, a placa-mãe recebe todos os 60 quadros/s fluidos, enquanto a memória RAM é estritamente contida a exatamente 20 quadros/s (40 quadros descartados com segurança a cada segundo), eliminando o congelamento do OpenRGB.
- **Deduplicação de cores no Studio:** a correção de `forceSend` em ticks espaciais reabilita a deduplicação inteligente de cores para componentes cujos pixels não sofreram alteração no mapa espacial, poupando ainda mais o tráfego do transporte local.
- **Suíte de testes completa:** 168 testes automatizados aprovados (`npm test`, 0 falhas) incluindo testes dedicados de ticks espaciais concorrentes no Studio.

Consulte o [plano de melhorias](../PLANO-MELHORIAS.md) e o [contexto de desenvolvimento](../CONTEXTO-DESENVOLVIMENTO.md). Executáveis Nexus continuam sem assinatura digital própria.
