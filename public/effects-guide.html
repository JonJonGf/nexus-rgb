NEXUS RGB ↗

Crie efeitos para seu setup

Uma fórmula Nexus descreve cores e movimento com dados, sem código executável. Este guia acompanha o app e funciona sem Internet.

Do rascunho às luzes

  1. No Mapa do setup, abra Trocar efeito → Criar efeito +. Use os controles ou cole seu JSON em Editar JSON · avançado.
  2. Clique em Testar prévia. O desenho usa a mesma fórmula do motor e acompanha o JSON válido enquanto você edita. Pausar prévia congela o tempo; editar ainda redesenha o rascunho.
  3. Salvar na biblioteca guarda sem ativar. Salvar e aplicar guarda e seleciona o efeito nas luzes. A opção de Perfis cria também um perfil. Componentes desligados continuam desligados.
A prévia do editor não envia comandos aos LEDs. Ela mostra a fonte de cores, sem simular posição, brilho ou estado dos seus componentes. Depois de aplicar, o mapa mostra as últimas cores enviadas, sem leitura física do hardware.

Rainbow Cascade

Este exemplo move o arco-íris de cima para baixo. Para manter as cores paradas, troque wave por gradient.

{
  "format": "nexus-effect/1",
  "name": "Rainbow Cascade",
  "pattern": "wave",
  "palette": [
    "#ff0000", "#ff7f00", "#ffff00", "#00ff00",
    "#00f0ff", "#0000ff", "#7f00ff"
  ],
  "speed": 40,
  "angle": 90,
  "scale": 1.2
}

Padrões disponíveis · pattern

patternComo se comporta
waveOnda contínua com transições suaves entre as cores. Segue angle.
cometFaixa luminosa com rastro e intervalos escuros. Segue angle.
ringsAnéis que se expandem a partir do centro. A simetria radial torna angle visualmente irrelevante.
gradientGradiente estático. Usa a paleta, angle e scale. speed não o anima.
scannerVarredura · feixe que vai e volta
rainChuva · rastros em sequência
spiralEspiral · braços de cores
plasmaPlasma · nuvens em movimento
fireFogo · chamas e turbulência
sparkleCintilação · pontos que acendem
ripplesOndulações · ondas que se encontram
blocksBlocos · mosaico em movimento

Campos e limites

Todos os campos abaixo são obrigatórios. Os números aceitam decimais; use ponto decimal no JSON.

CampoValor e significado
format"nexus-effect/1"
nameNome do efeito: 1 a 60 caracteres.
patternwave | comet | rings | gradient | scanner | rain | spiral | plasma | fire | sparkle | ripples | blocks
paletteDe 1 a 8 cores #RRGGBB, em ordem. A última transita de volta para a primeira; uma cor produz uma paleta uniforme.
speed0 a 100. Controla a velocidade da animação, não os FPS. Zero mantém o quadro parado.
angle−360 a 360 graus. 0: esquerda → direita; 90: cima → baixo; 180: direita → esquerda; −90: baixo → cima.
scale0.1 a 10. Valores maiores repetem mais a paleta no espaço, criando faixas mais estreitas.

Quando algo não parece certo

JSON inválido exibe um erro e bloqueia testar/salvar. Confira aspas duplas, vírgulas, chaves e os limites. O editor aceita um rótulo JSON ou cercas de Markdown ao colar; o arquivo .json importado deve conter somente o objeto JSON.

Salvar uma fórmula alterada cria outro item na biblioteca; não substitui perfis antigos. JSON não executa JavaScript, expressões, áudio ou integrações. O limite de importação é 128 KiB por arquivo e 64 efeitos importados.

Para a onda atravessar as peças, aplique o efeito espacial e confira posição, quantidade e ordem dos LEDs no mapa. É necessário Direct com cor por LED. Hubs que espelham o sinal não permitem controlar cada fan separadamente.

HTML / Canvas do SignalRGB

No criador, escolha SignalRGB · HTML / Canvas ou cole o HTML completo com canvas e script. Testar prévia valida o código e mostra os controles das metatags. Alterar código ou parâmetros pausa a prévia; teste novamente para reiniciar.

O HTML executa em QuickJS dentro de um processo isolado. O navegador recebe somente imagens. A prévia acompanha o FPS configurado para o motor, exibindo até 10 imagens por segundo; não salva nem altera as luzes.

Compatibilidade parcial: Canvas 2D, requestAnimationFrame, timers e controles color, number, boolean e combobox. Booleanos chegam como 0 ou 1. Áudio, WebGL, rede, arquivos e scripts ou imagens externos não são suportados.

Salvar e aplicar guarda o HTML e os parâmetros escolhidos e ativa o efeito. Guardar também em Perfis permite recuperar esses parâmetros depois. Nome e autoria do arquivo são preservados.

Para chuva de cima para baixo, use rain com angle 90. Para fogo subindo da base, use fire com angle -90 e uma paleta amarela, laranja e vermelha.
